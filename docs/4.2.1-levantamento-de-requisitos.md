# 4.2.1 Levantamento de Requisitos

## 1. Como os requisitos foram levantados

Os requisitos do IceTech foram definidos a partir do problema apresentado na descrição do projeto e das necessidades de uma sorveteria. Também foi considerado o que o atendente e o gerente precisam fazer durante o atendimento.

## 2. Da fala à necessidade

| Nº | Fala do cliente | Classificação | Necessidade por trás |
|---|---|---|---|
| F1 | Quando tem bastante movimento, fica difícil controlar todos os pedidos. | necessidade | Organizar os pedidos dos clientes. |
| F2 | Às vezes preciso conferir se ainda tem determinado sabor antes de vender. | necessidade | Consultar os sabores disponíveis. |
| F3 | É difícil saber quanto ainda tem de cada sabor no estoque. | necessidade implícita | Controlar as quantidades disponíveis em estoque. |

## 3. Histórias de usuário

| Nº | História de usuário | Veio de |
|---|---|---|
| HU01 | Como atendente, quero registrar os pedidos dos clientes pra manter os pedidos organizados. | F1 |
| HU02 | Como atendente, quero consultar os sabores disponíveis para informar os clientes. | F2 |
| HU03 | Como gerente, quero acompanhar o estoque para saber quais sabores ainda tem. | F3 |

## 4. Requisitos funcionais

| Nº | Nome | Requisito | Veio de |
|---|---|---|---|
| RF01 | Registrar pedido | O sistema deve registrar os pedidos dos clientes. | HU01 |
| RF02 | Consultar sabores | O sistema deve mostrar os sabores disponíveis. | HU02 |
| RF03 | Cadastrar sabor | O sistema deve permitir cadastrar novos sabores. | HU02 |
| RF04 | Atualizar estoque | O sistema deve atualizar a quantidade de cada sabor em estoque. | HU03 |
| RF05 | Consultar pedidos | O sistema deve mostrar os pedidos registrados. | HU01 |

## 5. Requisitos não funcionais

| Nº | Categoria | Requisito |
|---|---|---|
| RNF01 | Desempenho | As informações de sabores, estoque e pedidos devem aparecer rapidamente. |
| RNF02 | Acesso | Apenas usuários autorizados poderão alterar o estoque. |
| RNF03 | Dispositivo | O sistema poderá ser acessado pelo navegador em um computador da sorveteria. |

## 6. Conferência com a 4.1

| Item da 4.1 | Requisito relacionado |
|---|---|
| Cadastrar os sabores disponíveis | RF03 — Cadastrar sabor |
| Registrar os pedidos dos clientes | RF01 — Registrar pedido |
| Consultar os sabores disponíveis | RF02 — Consultar sabores |
| Atualizar a quantidade de produtos em estoque | RF04 — Atualizar estoque |
| Consultar os pedidos realizados | RF05 — Consultar pedidos |
