# 3.1 Abordagem de Desenvolvimento

O projeto seguirá uma abordagem **iterativa e incremental**, desenvolvendo o sistema aos poucos, começando pelas funcionalidades mais importantes.

A cada etapa, o projeto será revisado e comparado com as seções anteriores. As versões serão registradas no repositório e as partes principais poderão ser apresentadas ao cliente.

Essa abordagem permite fazer ajustes durante o desenvolvimento, diferente do modelo em cascata. O projeto não seguirá o Scrum completo, pois será desenvolvido em um contexto acadêmico, sem os papéis e cerimônias formais do Scrum.
