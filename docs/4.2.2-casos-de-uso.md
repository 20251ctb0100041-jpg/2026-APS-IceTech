# 4.2.2 Modelagem de Casos de Uso

## Atores

Dois papéis usam o IceTech: o Atendente e o Gerente. O ator representa o papel de quem opera o sistema, não uma pessoa específica.

| Ator | Quem é | O que faz no sistema |
|---|---|---|
| Atendente | Pessoa que atende os clientes na sorveteria | Registra os pedidos e consulta os sabores disponíveis |
| Gerente | Pessoa responsável por acompanhar o funcionamento da sorveteria | Cadastra sabores, acompanha o estoque e consulta os pedidos realizados |

## Casos de uso

Cada caso de uso representa um objetivo que um ator alcança usando o sistema. Os nomes devem ser iguais aos dos requisitos funcionais da seção 4.2.1.

| Caso de uso | Ator | Atende |
|---|---|---|
| Registrar pedido | Atendente | RF01 |
| Consultar sabores | Atendente | RF02 |
| Cadastrar sabor | Gerente | RF03 |
| Atualizar estoque | Gerente | RF04 |
| Consultar pedidos | Gerente | RF05 |

## Especificação do caso de uso principal

Aqui fica o detalhamento do fluxo mais importante do IceTech: o **Registrar pedido**.

| Campo | Conteúdo |
|---|---|
| **Caso de uso** | Registrar pedido |
| **Ator principal** | Atendente |
| **Pré-condição** | Atendente logado e sabores já cadastrados no sistema |
| **Pós-condição** | Pedido salvo no banco e quantidade do estoque atualizada |

### Fluxo principal
1. O atendente inicia um novo pedido.
2. O sistema mostra os sabores disponíveis e quanto resta de cada um em estoque.
3. O atendente escolhe o sabor e a quantidade que o cliente pediu.
4. O sistema calcula o valor total do pedido na hora.
5. O atendente confirma o pedido.
6. O sistema salva o registro, desconta do estoque e confirma na tela que deu tudo certo.

### Fluxo alternativo: Sabor com estoque baixo (FA01)
* **No passo 2 do fluxo principal:** Se o estoque de um sabor estiver no limite (pouca quantidade), o sistema mostra um aviso de alerta na tela para avisar o atendente, mas deixa selecionar normalmente enquanto houver unidades.

### Fluxo de exceção: Sabor esgotado ou insuficiente (FE01)
* **No passo 3 do fluxo principal:** Se a quantidade pedida for maior do que tem no estoque, o sistema avisa que não dá para concluir, trava a confirmação e pede para o atendente mudar o sabor ou a quantidade.
